# Credit-Card-Customer-Segmentation-and-Behavior-Based-Profiling-
• Analyzed 660 credit-card customer records across five banking features to identify patterns in customer behavior
• Removed identifiers and applied percentile-based outlier capping and standardization before fitting K-Means
• Selected three K-Means clusters using the Elbow Method and Silhouette Score, achieving a value of 0.516
• Developed customer profiles from cluster averages to guide targeted engagement strategies for each segment
